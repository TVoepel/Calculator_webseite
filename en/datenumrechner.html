Formula & Reference Values

Result = value × factor(from) ÷ factor(to), base unit = 1 byte Decimal (SI, base 1000): 1 kB = 1000 B, 1 MB = 1000 kB, 1 GB = 1000 MB Binary (IEC, base 1024): 1 KiB = 1024 B, 1 MiB = 1024 KiB, 1 GiB = 1024 MiB 1 byte = 8 bits

Operating systems and manufacturers use these prefixes inconsistently: hard drive manufacturers usually calculate decimally (1 TB = 1000 GB), while RAM, for example, is traditionally given in binary. This converter clearly distinguishes between the two systems (kB/MB/GB = decimal, KiB/MiB/GiB = binary).

Sources: NIST – Reference on binary prefixes, IEC – Prefixes for binary multiples, Wikipedia – Byte

All Supported Data Units

With this data size converter, you can directly convert bits, bytes, kilobits, kilobytes, kibibytes, megabits, megabytes, mebibytes, gigabits, gigabytes, gibibytes, terabytes, and tebibytes.

Bit units (kbit, Mbit, Gbit) are mostly used for transfer speeds (internet, network), while byte units (kB, MB, GB) are used for file sizes and storage space.

In Practice: When You Need to Convert Data Sizes

Internet providers advertise download speeds in Mbit/s – but you calculate a file's actual download time using MB or GB, which easily leads to confusion.

Storage manufacturers calculate hard drive and SSD capacity decimally (1 TB = 1000 GB), but operating systems often display free space in binary (GiB) – which is why a new hard drive looks smaller in Explorer than what's printed on the box.

For streaming, cloud storage, and mobile data plans, converting between units helps you gauge your actual data usage realistically.

Frequently Asked Questions

Why is my hard drive smaller than advertised?

Manufacturers calculate 1 TB = 1000 GB (decimal, SI prefixes), but Windows displays storage in GiB (binary, base 1024). A 1 TB hard drive therefore shows only about 931 GiB in Explorer.

What's the difference between Mbit and MB?

1 byte equals 8 bits. Internet speeds are given in Mbit/s (megabits), file sizes in MB (megabytes) – so 100 Mbit/s is only 12.5 MB/s of download speed.

What is a kibibyte (KiB)?

A kibibyte (KiB) equals exactly 1024 bytes (2¹⁰) and was introduced by the IEC to clearly distinguish binary prefixes from decimal ones (1 kB = 1000 bytes).

How long does a download take at 100 Mbit/s?

At 100 Mbit/s (= 12.5 MB/s theoretically, somewhat less in practice), downloading a 5 GB file takes roughly 400 seconds, or about 6–7 minutes.

How many GB is a terabyte?

1 terabyte (TB, decimal) equals 1000 GB. Its binary counterpart, the tebibyte (TiB), has 1024 GiB instead.
